Install on Windows

One Setup EXE. No ZIP to unpack or Python to install yourself.

This preview is not Windows code-signed. Windows may show an unknown-publisher or reputation warning. Verify that your download came from the official GitHub release.

  1. Download the Windows EXE from the download page.
  2. Save your project and close After Effects.
  3. Open CapForge-0.3.3-Windows.exe. Setup prepares a private runtime, then opens the install window.
  4. Review the unsigned Adobe extension option. This preview needs it; it permits all unsigned Adobe panels for your account.
  5. Click Install CapForge. Keep an internet connection available until installation finishes.
  6. Reopen AE and choose Window → Extensions → CapForge, or Extensions (Legacy) if that is your menu label.

Your first captions

In Setup, start the service and add one provider API key, or explore the built-in demo. In Source, choose a short clip and language. Transcribe, review your words, choose a look, and generate captions into a new precomp.

If Windows shows a warning

Check that the EXE came from the official CapForge GitHub release. Do not turn off antivirus or SmartScreen globally. If your computer is managed by work, ask your administrator whether this preview is allowed.

Updating and repairing

Choose Setup → Check for updates → Update inside CapForge. It downloads and verifies the Windows package automatically. Save your work, close AE, complete Setup, then reopen AE. You can also rerun the latest EXE to repair an installation.

Where your work lives

The service and exports live in %LOCALAPPDATA%\CapForge. Older owned installations keep their existing folder. Your API keys and exports survive updates. Export JSON to save transcript edits; save the AE project separately.

More help

Read the full guide on GitHub or report an issue. Include your OS, AE version, CapForge build and the error message. Never include API keys.
