# CapForge fresh review — 12 November 2026

This review started from published commit `7e3739a` on `kml`. The changes below
are prepared for the next tested build on that branch. Public version remains
0.3.2; the build commit identifies each update. Publication is gated by the
[release workflow](https://github.com/MeticulousTransformer/CapForge/actions/workflows/release.yml).
Use its successful build and attached release ZIP for installation, rather than
a locally generated review archive.

## What was fixed

| Area | Confirmed problem | Result |
| --- | --- | --- |
| Update recovery | A failed install restored old code but left changed Python packages | Working dependencies are backed up before pip; rollback restores both |
| Paid transcription | One ElevenLabs failure could trigger repeated uploads and silently downgrade the model | One attempt keeps the selected model; account errors give a useful next action |
| Word timing | Missing times became zero, some invalid values passed, document duration could end too early | Validate genuine intervals, retain precision, cover every final endpoint |
| Provider evidence | Timing failure inside an adapter discarded a received response | Save the raw response before reporting unusable timing |
| Confidence | Valid zero confidence became 1.0 | Distinguish zero from a missing value |
| Local Whisper | Shared temporary output could reuse an earlier transcript | A fresh private output directory for each run |
| Service shutdown | Audio extraction could be interrupted by an update | Extraction shares the work lock; admitted requests recheck shutdown |
| Errors | Raw HTTP bodies and generic media failures were shown to editors | Account/network/audio guidance without echoing arbitrary response bodies |
| AE cleanup | A name prefix was treated as proof of ownership | Only marked generated comps are cleared; unmarked older comps remain |
| AE failure | An unfinished precomp remained after generation failed | Remove only the new partial result; close the Undo group |
| Caption layout | Fitted lines overlapped and backgrounds used incomplete glyph bounds | Use actual top/bottom extents and all positioned word bounds |
| Layer stacking | A solid background could cover active-word boxes | Put the caption background behind generated extras |
| AE tracking | Fitting generated fractional tracking; real AE rejected it | Round tracking at the TextDocument assignment; retain source timing precision |
| Input validation | String/boolean/null values were accepted through coercion | Host checks actual types; panel checks numeric word references |
| Legacy controls | Zero coordinates, spacing and margin became defaults | Preserve valid zero settings |
| Provider switching | Previous provider's custom model stayed selected | Clear model on provider change; preserve it on reconnect |
| Service startup | Starting the service still required a manual connection check | Poll readiness with bounded health requests and actionable failure details |
| Older panel browsers | New cancellation API could be missing | Feature detection plus timeout fallback |
| Documentation | Main README mixed modern guided setup with outdated manual instructions | One editor installation path first; developer commands separated |

## Evidence

Final `python scripts/check_release.py --package` run passed:

- 102 backend tests.
- 32 installer tests.
- 11 release/package tests.
- 132 JavaScript AE/panel tests (93 AE, 39 panel).
- Version parity and shell syntax checks.
- Local allowlisted ZIP creation; archive checks verify checksum, manifest,
  launch permissions and matching version. This Mac build has the Windows CMD
  fallback, not the native Windows EXE built by hosted CI.

The first sandboxed run could not bind temporary localhost servers. It was
rerun with local-network permission; that environmental error was not hidden
or treated as a product failure.

Regressions were reproduced before fixes. Independent cross-review caught
additional adapter defaults and panel compatibility/error-reporting mistakes,
which were corrected before the final run. Test totals count test cases;
some tests contain several provider or malformed-input subcases.

## Remaining acceptance work

This review improves reliability; it does not establish a finished commercial
product on every supported system.

1. Run Windows, Intel Mac and Apple Silicon packaged-download CI on the new
   commit before publishing. Earlier successful CI belongs to `7e3739a`.
2. Test the current native installer UI and downloaded-file OS prompts on clean
   Windows and Mac machines. Sign/notarize distribution and sign CEP before
   removing reliance on unsigned-extension mode.
3. Try short real Georgian and English recordings with an authorized provider
   account. No paid calls or personal clips were used in this review. SDK/model
   availability and transcription accuracy remain provider-specific.
4. Validate other AE versions and real playback over time, including varied
   fonts, portrait compositions, edited footage and long sessions. Still frames
   and inspected keyframes do not establish every motion/font combination.
5. Let unfamiliar editors complete install → first captions → update without
   coaching. Record every point where they need help.

Known workflow limitations are explicit in the quick-start: full-source
transcription ignores selected-layer trims/offsets/speed, and edited transcripts
must be exported before closing. Google/local providers still need additional
setup. Update rollback backups consume disk space proportional to the installed
Python environment. These are priorities for subsequent small improvements.
